Introdução ao Next:

O Next é um framework desenvolvido a partir do ReactJS em 2016 por Guilherme Rauch (Cofundador da Vercel), é sistema opinativo com estrutura e ferramentas já definidas. Para evitar a criação de conceitos especificos que atrasam o projeto.

O que o Next tem/faz?

  • Tem suporte a SPA, SSG e SSR
  • Contém o CSS no Javascript
  • Não a necessidade de configuração inicial (rotas, hot reloding, code splitting, etc, são por padrão)
  • 100% extensível (Controle completo)
  • E otimizado para a produção

    • SSG:

    É útil para sites simples, sem muita interação, quando o conteúdo muda pouco. Quando se quer uma performance maior, como em Landing Pages, Blogs, Portifólios, etc.

    Vantagens:

  • Uso quase nulo do servidor
  • Pode ser servido numa CDN
  • Melhor performance
  • Flexibilidade para usar qualquer servidor

    • Desvantagens:

  • Tempo de build maior
  • Dificuldade de escalar a aplicação
  • Dificuldade de lançar atualizações constantes

    • SPA:

    Ideal para sites que exigem inúmeras interações sem refresh, informações diferentes para diferentes usuários, autenticação do usuário e sem muita necessidade de indexar informações, como Twitter Web, Facebook Web, Spotify, Sites internos de empresas, etc.

    Vantagens:

  • Permite interações sem carregar
  • Site rápido após o primeiro carregamento
  • Otimo para aplicações Web
  • Possui diversas bibliotecas

    • Desvantagens:

  • Carregamento inicial demorado
  • Performance imprevisível
  • Dificuldade no SEO
  • A maioria do conteúdo não é indexado

    • SSR:

    Utilizado quando se quer um SPA com carregamento menor, quando o conteúdo é dinâmico, contêm muitas páginas e quando se quer ótima indexação de conteúdo, como em Ecommerces, Sites de Notícias, etc.

    Vantagens:

  • Ótimos para SEO
  • Meta tags com previews mais adequados
  • Melhor performance para o usuário
  • Código compartilhado com o backend Node
  • Menor processamento no usuário

    • Desvantagens:

  • Demora no primeiro carregamento
  • HTML maior
  • Reload completo nas mudanças de rota* (pode ser contornado com macetes)
